# TODO: перенос greenexp.ru → geometki.com

Цель: освободить место на хостинге greenexp.ru и при этом сохранить редиректы со старых карточек мест на geometki.com (301) и поисковый вес.

Сейчас соответствие «старая страница → место на geometki» вычисляет PHP-бэкенд greenexp.ru по своей базе данных. Таблица больше не меняется, поэтому её можно один раз выгрузить в статичный файл и обходиться без базы.

## Итоговая схема

На хостинге greenexp.ru остаются только три файла:

```
.htaccess        — все запросы отправляет в index.php
index.php        — редиректор (301)
redirects.php    — массив «старый путь → новый URL», генерируется один раз
```
